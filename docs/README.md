# Planning docs

These files are the living plan. Update them as we build; they are the source of truth for where the project is.

| File | Purpose | Update when |
|---|---|---|
| [VISION.md](VISION.md) | What we're building, for whom, and what makes it different | Direction changes |
| [ROADMAP.md](ROADMAP.md) | Phases, tasks, status checkboxes, exit criteria | Every task starts/finishes |
| [ARCHITECTURE.md](ARCHITECTURE.md) | How the pieces fit; target design vs. current code | Design changes or modules land |
| [DECISIONS.md](DECISIONS.md) | Decision log (what we chose, why, alternatives) | Any non-trivial choice |
| [PROGRESS.md](PROGRESS.md) | Dated build journal, newest first | End of every work session |
| [CREDITS.md](CREDITS.md) | Upstream projects and licenses we owe attribution to | A dependency/inspiration is added |

Workflow: plan in ROADMAP -> record choices in DECISIONS -> build -> log in PROGRESS -> tick the box in ROADMAP.
